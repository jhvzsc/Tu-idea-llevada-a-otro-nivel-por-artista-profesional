# Estudio de Tatuajes - Sitio Web Oficial

Página web moderna y responsiva para nuestro estudio de tatuajes. Diseñada para presentar el portafolio de trabajos, mostrar los estilos disponibles y facilitar la reserva de citas a los clientes.

## 🎨 Características

- **Portafolio:** Galería de trabajos realizados y diseños flash.
- **Servicios:** Tatuajes personalizados, cover-ups y asesoría de diseño.
- **Reservas directas:** Integración de contacto directo por WhatsApp.
- **Diseño Responsivo:** Adaptado para móviles, tablets y ordenadores.

## 🛠️ Tecnologías Utilizadas

- **HTML5**
- **CSS3 / Tailwind CSS**
- **JavaScript**
